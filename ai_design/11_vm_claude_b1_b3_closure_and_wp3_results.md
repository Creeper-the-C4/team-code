| 要求 | 处理 | 位置 |
| :--- | :--- | :--- |
| 公式编号：Seel 关节中心约束是**式 (7)**，不是式 (3) | **接受更正。** 我在 09 号文件 §1 中把编号写错了，式 (3) 是角速度主轴投影约束。T3 现已全部改为“Seel et al. 2014 式 (7)”，世界系向量式和范数式都注明是由式 (7) 得出 | `diag_accel_unit.py` 的模块说明、`knee_lever_arms` 的注释、README |
| 符号约定 | 已写明：Seel 原文的 $\mathbf o_i$ 由关节中心指向传感器，所以 $\mathbf o_i=-\mathbf r_i$，本项目的 $\mathbf r_i$ 由传感器指向关节中心 | 同上 |

| T1 增加第三种假设，不再强制二选一 | T1 现在的输出是 **`g` / `mps2` / `specific_force` / `filtered_or_unresolved`** 四者之一，判据如下 | `t1_signature`、`t1_hypothesis` |
| 补一条 specific-force 单测 | 合成夹具新增 `acc_unit='specific_force_g'`（加速度中保留重力），新增测试 `test_accel_unit_specific_force_is_a_third_hypothesis` | `make_synthetic_fixture.py`、`tests/test_diag_p0.py` |

**T1 的判据。** 用到两个量：一段跳跃里躯干竖直通道的均值，与该通道 5–95% 分位数跨度之比（下称“均值比”）；以及腾空时是否有贴近 0 的平坦段。

| 判为 | 条件 |
| :--- | :--- |
| `g` 或 `mps2`（自由加速度） | 均值比的绝对值小于 0.10，且存在共同的负平台。平台在 [−1.25, −0.75] 判为 g，在 [−12, −7.5] 判为 m/s² |
| `specific_force` | 均值比大于 0.25，且两次落地之间存在接近 0 的平坦腾空段。原理：周期性跳跃中，比力的平均值等于 +g |
| `filtered_or_unresolved` | 以上都不满足，例如滤波把平台压到 −0.75 以上 |

**夹具实测，三种假设完全分开：**

| 夹具 | T1 | 平台 | 均值比 | 平坦零段数 | 最终结论 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| g | g | −1.000 | −0.005 | 0 | `g` |
| m/s² | mps2 | −9.807 | −0.005 | 0 | `mps2` |
| specific force | specific_force | — | 0.502 | 24 | `specific_force` |

**新发现，写入说明：T2 对重力这类常值偏置不敏感。** T2 每一步都做线性速度去趋势，常值加速度积出来的速度正好是线性的，会被完整去掉。所以分工是：**T2 定加速度的单位量级，T1 定重力有没有去掉**。最终结论是：

- `g` 或 `mps2`：仅当 T1 与 T2 判定一致时给出；
- `specific_force`：只要 T1 判定是比力就给出；
- 其余情况一律给 `filtered_or_unresolved`。

## 2. B2 闭环：Task 1/2 特征与屏蔽冻结规范（V4.0 定稿）

**总原则：**
- 每个特征 $f$ 都有一个依赖集 $\mathrm{Deps}(f)$。训练和评估布局 $S$ 时，只允许使用 $\mathrm{Deps}(f)\subseteq S$ 的特征。
- 特征**先屏蔽、后计算**，沿用队友 loader 的约定。
- 窗口为 2 s 和 4 s 两种，以及多尺度组合；均不跨试次。

| 编号 | 定义（按传感器、按窗口） | 维数/传感器 | 依赖集 Deps | 是否用到四元数 |
| :--- | :--- | :---: | :--- | :--- |
| **F1^W** | 世界系 Acc/Gyr 的 X/Y/Z 各取均值、标准差、RMS、极差（24）；Acc 与 Gyr 的模长各取均值、标准差、RMS（6）；Acc_Y 的主频与 0.5–4 Hz 峰占比（2）。即队友现有的 32 维 | 32 | {本传感器} | 否（但随航向变化） |
| **F1^B** | 与 F1^W 统计量相同，但先用本传感器四元数把向量转到它自己的体系：$v_b=R(q)^\top v_w$ | 32 | {本传感器} | **是** |
| **F1^H** | 对 Acc 和 Gyr 分别取水平模长 $\sqrt{X^2+Z^2}$ 和竖直分量 $Y$，各算均值、标准差、RMS、极差（16）；再加模长统计（6）和 Acc_Y 的主频与峰占比（2）。**对绕 Y 轴的航向旋转严格不变，且完全不用四元数** | 24 | {本传感器} | **否** |
| **F2** | 队友现有的 8 维：$R(q)$ 的前两列（6D 表示）加 2 项旋转增量统计 | 8 | {本传感器} | 是 |
| **F2′** | 5 维：窗口中心帧 $R(q)$ 的第 2 行 $(R_{10},R_{11},R_{12})$，加上 $\overline{\Delta\theta}$ 和 $\mathrm{RMS}(\Delta\theta)$，其中 $\Delta\theta_t=\|\mathrm{Log}(R_t^\top R_{t+1})^\vee\|_2$ | 5 | {本传感器} | 是 |
| **F3** | F1^W + F2，即队友现有的完整 40 维 | 40 | {本传感器} | 是 |
| **F4** | F3 加上相对姿态与拓扑特征。父子节段的相对旋转 $R_p^\top R_c$ 的 6D 表示、相对角速度幅值，以及大腿相对 LowerBack 的摆幅等 | 按对 | $\{p, c\}$，两者都在 $S$ 中才计算 | 是 |

**补充约定：**
- **F2 与 F2′ 的比较。** 两者的差值同时包含“维数不同（8 维对 5 维）”和“是否保留水平方向信息”两个因素，**不能称作“纯粹的航向干扰损失”**。航向敏感性另做专门检验：在验证集参与者上，对所有世界系向量和四元数施加**同一个** $Q_y(\psi)$（$\psi\in\{\pm30°,\pm90°,180°\}$），比较各特征集 Macro-F1 的变化。F1^H 和 F2′ 理论上应当不变，可以借此验证。
- **Task 2 的独立性底线。**
  - **代码级独立**指 $\mathrm{Deps}(f)\subseteq S$，由程序强制执行。
  - **测量来源独立**则要等 P0 的 `diag_orientation_independence` 给出实证；在此之前，厂商四元数可能是全身融合解算的产物。
  - 因此：**Task 2 的主结果（严格硬件屏蔽）只用 F1^H**，也就是只用 Acc/Gyr；
  - F1^H+F2′ 和 F4 的结果都标为**条件性结果**，注明“依赖厂商四元数，测量来源独立性未证实”。
- **跑步机定速修正（原论文：0.9 / 1.2 / 1.5 m/s）。**
  - 三档步行的标签本身是**绝对速度**，所以**运动学估计速度 $\hat v=2L\sin(\Delta\theta_{th}/2)\cdot f_{\text{step}}$ 是主特征**。其中 $f_{\text{step}}$ 在 ≥4 s 的窗口上用自相关加抛物线插值求得；$\Delta\theta_{th}$ 是大腿摆幅；$L$ 是大腿加小腿长度，取自人体测量表这一允许使用的元数据。$\hat v$ 的依赖集是 {大腿} 加人体测量数据。
  - 无量纲步频 $f\sqrt{L/g}$ 和 Froude 数 $\hat v/\sqrt{gL}$ **只作消融对照**。
  - “个人常速自标定”**不再作为主假设**。
  - 这还带来一个新的**外部参照**：`diag_subject_protocol` 已新增“运动学 $\hat v$ 对比跑步机速度 0.9/1.2/1.5 m/s”的检验。这是全题第一个来自实验协议、而不是来自 IMU 本身的定量参照。论文中称为“协议标称速度参照”，不能称作独立的动捕真值。
- **对 Task 3 的连带修正。** 跑步机上行走时，骨盆在世界系中的水平位移约为 0。所以：
  - 步行类的全局位移应改为在**皮带系**中表述；
  - 接触锚点的速度应设为 $-v_{\text{belt}}$，而不是 0。从一个支撑相积分到下一个支撑相、两端速度相等时，算出的仍是相对皮带的步幅，T2 的检验依然成立，模块说明里已写明；
  - 每档步行的平均水平速度可以拿已知的皮带速度来验证。
- **批次表述。** P01–P24 / P25 / P26–P30 只作为描述性分组。原论文没有说明它们是不同的采集批次，**不得写成“不同批次”**。README 已改。

**核心结论：**
1. **加任何单个传感器，都无法仅靠传感器辨识 L1–S1 的总腰椎屈曲**，至少需要“L1 + 骶骨”或“C2a + 骶骨”两个传感器。这正好构成 Task 4 中“一个传感器不够 → 小幅扩展”的递进论证。
