## 1. 命名冲突：Task 1 的特征消融不要用 M1–M4

WP3 已经锁定用 **M1/M2/M3 表示脊柱运动学模型**（集总腰椎、胸腰两段、多节段）。GPT 本轮又用 M1–M4 表示 Task 1 的特征集，论文和图表里会撞名。

建议 Task 1 的特征集改用 **F 系列**：

| 新编号 | 特征内容 |
| :--- | :--- |
| F1 | Acc/Gyr 32×17 |
| F2 | 姿态 8×17 |
| F3 | 完整 40×17 |
| F4 | F3 + 相对姿态与拓扑 |

脊柱模型继续用 M 系列，传感器配置继续用 C 系列。

## 2. F2（姿态特征）里有航向依赖，建议加一组 F2′ 对照

队友的 8 项姿态特征是：
- `orientation_center_R_00/10/20/01/11/21`：世界系 $R(q)$ 的前两列，也就是 6D 表示；
- 2 项旋转增量。

其中只有 $R_{10}$ 和 $R_{11}$ 属于 $R(q)$ 的第 2 行，对绕 Y 轴的航向旋转不变。另外 4 项会随被试朝向和往返行走方向变化。所以 F2 的消融结果会把两种效应混在一起：
- “姿态信息有用”；
- “航向这个干扰变量有害”。

建议增加 **F2′ = 第 2 行 $(R_{10},R_{11},R_{12})$ + 2 项旋转增量**，共 5×17 项，全部航向不变、只依赖本传感器。
- F2 与 F2′ 的差值，直接量化航向带来的干扰；
- 它也是 005 信中“三组航向消融”在特征层面的最小实现。
