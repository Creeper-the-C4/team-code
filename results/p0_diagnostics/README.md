## 主要结论

### 加速度语义与单位

固定规则判定为 **`g`**，T1与T2一致。跳跃腾空平台中位数为 -0.981693，MAD为 0.024595；按g换算后的楼梯步幅抬升中位数为 0.331785 m，水平步幅为 1.182494 m。

这支持缓存为已经去重力的自由加速度、数值单位为g。结论来自脚本预注册的内部物理一致性规则，不是外部仪器校准。后续需要SI加速度时，应在派生计算中乘9.80665，不再次去重力；本轮没有改写原始缓存或自动启用Task 3加速度因子。

### 四元数独立性

左右膝、左右肘均未触发 `skeleton_constrained_suspected`。未触发阈值不能当作硬件独立或误差完全独立的证明。详见JSON中的陀螺仪与四元数残差自相关、腿段残差相关性及完整采样统计。

### 被试与协议

六折审计通过：训练、验证、测试参与者互斥，每人恰好测试一次，六折测试集合均覆盖13类。

步频慢中快严格递增检查未通过的参与者为 [2, 3]；三速信息不完整的参与者为 [7, 25]，不能计作通过。

P01至P24、P25、P26至P30的记录结构存在差异，但这里只按编号作描述性分组，不据此断言它们来自不同采集批次。

划船误判为坐的873个OOF窗口中，约80.53%位于试次中间80%的区间，而该区间本身占试次长度的80%。仅凭这一分布不能认定错误显著集中在中段。
