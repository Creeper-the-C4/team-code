# 第一题 V4 全量验证结果报告

第一题本轮30人全量对照实验已完成：**8组配置、48折训练全部结束并通过运行脚本核验**。实验于 **2026年11月28日 12:37:49（北京时间）** 完成，48个模型和逐窗口预测保留云端。本轮范围是第一题的活动识别；第二、三题尚待全量实测，第四题已有离线可观性分析。

本轮两项主指标最高的配置为 **F1B、2秒窗口、离线 Sticky HMM**：被试等权13类 Macro-F1为 **90.74%**，合并窗口13类 Macro-F1为 **94.11%**。这是同一套六折上的探索性对照结果，尚无独立确认数据。

## 数据与评估规则

- 30名参与者、2381个试次，60 Hz；2秒窗口220702个，4秒窗口108613个。窗口不跨试次边界，保留Others及过渡片段，标签共13类。
- 固定六折，每折20人训练、5人验证、5人测试，每人恰好一次外层测试。内部验证人员固定，并非完整嵌套交叉验证。
- 全组采用同一LightGBM配置，每次最多300轮，学习率0.08、31个叶子、最多12线程；提前停止依据验证集13类 Macro-F1。
- Sticky HMM的持续时间、转移与先验仅由当折训练人员估计。解码按已知试次边界离线运行，使用后续窗口，结果不能直接解释为实时识别性能。
- 被试等权指标先计算每人的固定13类 Macro-F1再平均；合并指标先汇总所有测试窗口再计算。无出现且无预测的类别按0计入固定13类平均，因此缺类人员的等权分数需结合类别覆盖理解。12个命名类指标仍基于全部窗口的混淆矩阵，包含Others引起的误报。

## 与旧基线的对应关系

旧基线被试等权为 **88.57%**、合并窗口为 **92.15%**。本轮 **F3、2秒、原始预测** 的两项指标均与旧基线完全一致，说明重跑复现了旧基线得分。

本轮最高配置相对旧基线分别提高约 **2.17个百分点**、**1.96个百分点**。该差值同时包含特征方案与平滑的变化，不应全部归因于HMM。仅在F1B自身内比较，HMM使被试等权提高 **1.52个百分点**、合并窗口提高 **1.46个百分点**。

## 结果解释与短板

1. **本轮8组均从离线HMM中获益。** 两项主指标在每组内均上升，但这一观察限于本次数据、协议与固定参数。
2. **复杂特征没有形成统一优势。** F1B加HMM在两项主指标上最高，F1H加HMM的合并指标为93.70%，可作为后续传感器精简的重要参照。姿态单独使用的F2p分数明显较低。
3. **4秒窗口不是统一改进。** F3和F4的原始预测在4秒下略高，但平滑后未超过各自2秒配置。2秒与4秒窗口网格、窗口数量及标签混合程度不同，不能当作相同窗口上的配对增益。
4. **Others仍是主要短板。** 八组的最低F1类别均为Others。本轮最高配置的Others F1为 **64.40%**，三档步行Macro-F1为 **94.44%**，划船F1为 **99.75%**；后续需重点分析过渡边界与Others混淆。
5. **最高配置属于探索性排序。** 本轮没有另留从未参与方案对照的独立测试集，也未新增差值显著性检验；不能据此宣称独立验证的最优或实时部署精度。
